Why should I file a tax return if tax is already deducted from my salary?

Filing keeps you on the active taxpayer list, which typically means lower withholding rates on banking, property and vehicle transactions.

Can you file my return if I live abroad?

Yes. Everything can be handled online through secure document sharing and video calls.
